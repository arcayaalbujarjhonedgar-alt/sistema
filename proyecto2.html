Desarrollo Web

El desarrollo web es el proceso de creación, construcción y mantenimiento de sitios y aplicaciones que se ejecutan en Internet a través de un navegador. El desarrollo web es la creación y mantenimiento de sitios y aplicaciones para Internet, dividido en front-end (la interfaz visual que ve el usuario) y back-end (la lógica, servidores y bases de datos que operan detrás de escena).
